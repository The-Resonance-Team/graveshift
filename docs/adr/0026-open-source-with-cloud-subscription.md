# Open source with a Cloud subscription option

Status: accepted

On 2026-11-22 the owner decided the product and license model.

Graveshift is the open-source product. A user self-hosts Graveshift on their own infrastructure. Cloud is Graveshift hosted by us on our infrastructure and sold by subscription. Both run the same product.

Personal use is free. Commercial use needs a yearly subscription.

There is no license check in code. Graveshift makes no cloud call and no call to us to check a license. The subscription is a commercial agreement, not a runtime gate.

Trade-off: no automated license enforcement. In return, self-hosted Graveshift stays fully open and makes no outbound license call.
