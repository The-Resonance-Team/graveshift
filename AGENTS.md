## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in this repo (uses the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles map to same-named labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout: `GLOSSARY-MAP.md` at the repo root indexes one `GLOSSARY.md` per `packages/<name>/` and `apps/<name>/` context. `GLOSSARY.md` and `docs/adr/` at the root cover system-wide terms and decisions. See `docs/agents/domain.md`.
