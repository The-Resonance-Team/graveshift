# GitHub App (Exorcist)

## Permissions
Repository permissions:
- Contents: Read & write (branches)
- Pull requests: Read & write
- Metadata: Read (mandatory)
- Checks: Read
- Actions: Read (optional, CI logs)
- Issues: Read & write (optional)

Never request: Administration, Workflows, Secrets.
Install only on selected repositories (the demo repo).

## Branch and PR rules
- Push only to `graveshift/*` branches (default prefix `graveshift/`); protect `main`.
- Branch name: `refs/heads/graveshift/inc-<shortid>-<slug>`.
- Create PRs with `draft: true`. Never call the merge API.
- Labels: `graveshift`, `exorcism`.

## Patch limits
Reject any patch that touches `forbiddenPaths` or exceeds the configured file/line size limits
before any push (SEC-6).

## PR body template
```markdown
## 👻 Exorcism for incident {{id}} — {{title}}
**Root cause (Medium, confidence {{conf}}):** {{rootCause}}
### Evidence (redacted)
{{#evidence}}- `{{type}}` {{ref}}: {{excerpt}}{{/evidence}}
### What changed
{{summary}}
### How to verify
{{verifySteps}}
### Risk
{{risk}}
---
🤖 Generated by Graveshift. Draft PR — never merged automatically. [Incident timeline]({{dashboardUrl}})
```

## CI / merge status
MVP: poll `GET /pulls/{n}` and check-runs every 30 s. Webhooks are a stretch goal.
